# Agent Instructions

Read this file before making changes in this repository.

## Project documents

- [plan00.md](plan00.md): the implementation plan. Follow it in order.
- [plan00-tracker.md](plan00-tracker.md): update it as you start and
  finish phases.
- [plan00-notes.md](plan00-notes.md): ask implementation questions
  here and check it for answers before starting each phase.

## Git commit rules

- Commit messages must be **wrapped at 72 characters**. This applies to
  the subject line and to every line of the body.
- Keep the subject line short (aim for 50 characters or fewer, and
  never more than 72). Use the imperative mood, for example
  "Add seeded RNG".
- Leave a blank line between the subject and the body.
- Use the body to explain what changed and why, not how.
- Make small, focused commits. Do not mix unrelated changes.
- Run lint, typecheck and tests before committing.
