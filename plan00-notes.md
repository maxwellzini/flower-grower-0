# Plan 00 Notes (Q&A)

A place for agents to ask implementation questions about
[plan00.md](plan00.md) and for the user to answer them in this same
file.

## How to use this file

**Agents:**
1. Add a new entry at the **bottom** of the "Questions" section using
   the template below. Use the next free number.
2. Keep the question specific. Say what you tried and what the options
   are. If you have a preferred option, say which.
3. Set `Status: Open`. If the question blocks your phase, also mark the
   phase `Blocked` in [plan00-tracker.md](plan00-tracker.md), and work
   on something unblocked if you can.
4. Check for answers before starting each phase. When an answer
   arrives, follow it, then set `Status: Answered` (or `Resolved` once
   acted on).
5. Never delete or rewrite someone else's text. Append only.

**User:** write your answer under the `A:` line and set the status to
`Answered`.

## Template

```
### Q<number>: <short title>
- Phase: <number>
- Status: Open | Answered | Resolved
- Asked: <date>

**Q:** <question, with context and options>

**A:** <answer goes here>
```
